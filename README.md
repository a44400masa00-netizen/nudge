# Nudge

3つのアプリを1つに合体させたものです。

1. 勉強コーチ（元のアイデア）: カレンダー・位置情報・スマホの使用状況から状況を推測し、他のアプリを見ていても画面上部にAIのメッセージをポップアップ表示して勉強を促す
2. しつこい通知（在宅学習）: 決めた時間帯に自宅にいると、対象アプリ（勉強アプリなど）を開くまで数分おきに通知でしつこく催促する
3. 音声アシスタント（デイリー機能）: 「ヘイ、デイリー」と呼びかけると起動する常駐の音声アシスタント。タイマー・アラーム・音楽再生・ライト・音量などをハンズフリーで操作できる

## GitHubでAPKを作る手順
1. GitHubのリポジトリの中身を、このzipの中身で置き換える（`.github`フォルダも含めて全部）
2. 「Actions」タブ →「Build APK」が自動で走る（走らなければ Run workflow）
3. 成功したら、実行結果ページ下の「Artifacts」から `app-debug-apk` をダウンロード→展開すると `app-debug.apk`
4. スマホにインストール
5. 失敗したら、赤い×の実行→失敗したステップのログ画面をスクリーンショット

## 初期設定の順番
1. ①の権限を、上から順に全部許可していく（マイクや通知へのアクセスなど、初回はダイアログが複数回出ます）
2. ②にGemini APIキーを入力（Google AI Studioで無料取得）
3. ③で自宅・学校・最寄り駅・塾の位置を地図で登録（在宅判定などにも使われる）
4. ④の動作を必要なら調整して保存
5. ⑤「見守りを開始」→④の声かけと⑥のしつこい通知がまとめて動き出す
6. 必要なら⑥でしつこい通知の対象アプリと時間帯を設定
7. 必要なら⑦で音声アシスタントの設定をして、有効にする

## この合体で変更した点（元の2つのアプリから）

- **在宅判定をひとつに統一しました。** 元の「しつこい通知」アプリはWi-FiのSSIDで自宅を判定していましたが、StudyNudge本体に既にある「自宅」の地図ピン（GPS）による判定に統一しました。Wi-Fiの登録は不要です。
- **通知の文面を少しやわらかくしました。** 元の文面には、放置が続いた時に強く突き放すような言い回しがありました。継続して頑張ってもらうという仕組み自体はそのまま活かしつつ、文面は「もう少し頑張りましょう」「今日はここまでにしましょう」といった、しつこいけれど厳しすぎない言い方に変えています。気に入らない場合は `app/src/main/java/com/example/studynudge/reminder/NotificationHelper.kt` の文言を書き換えてください。
- **「毎日◯時に開始チェック」専用のアラームを削除しました。** 見守り本体（NudgeService）が1分おきに全部まとめて確認する仕組みに乗せたので、別のアラームは不要になりました。むしろ元の15分おきより反応が早くなっています。
- **音声アシスタントは、Expo（React Native）で作られていたものを、Kotlinのネイティブ部分だけを取り出して移植しました。** 見た目の画面（React Native側）は使っておらず、常駐サービスが直接しゃべる・聞く形になっています。「ヘイ、デイリー」という呼びかけの言葉は、学習済みのモデルファイルに固定されているため、アプリ名を変えても変更できません（変えるには専用のモデルを作り直す必要があります）。

## ビルドが失敗しやすい箇所（優先度順）

1. **端末内AI（`dev.ffmpegkit-maintained:llama-android`）** 一番リスクが高い部分です。このライブラリの実際のAPI（クラス名・関数名）は、元のコードのコメント欄に「推測で書いている」と書かれていました。`Unresolved reference` のようなエラーが出た場合は、まず `app/build.gradle.kts` からこの1行を削除し、`voice/LocalLlm.kt` の中身を、常に例外を投げるだけの空実装に差し替えてください。それだけで、音声アシスタントはクラウド（Gemini）のみで問題なく動きます。
2. **呼びかけ検出（ONNX Runtime）** ライブラリ自体は安定していますが、`melspectrogram.onnx` と `embedding_model.onnx` をビルド時にネットから取得しています（`hey_daily.onnx` は同梱済み）。取得に失敗した場合は、ビルドのログにエラーが出ます。
3. **権限まわり** 音声アシスタント・しつこい通知は、使う権限の数がかなり多いです（マイク、通知へのアクセス、正確なアラーム、使用状況など）。実機で動かないときは、まずアプリ画面の①のボタンを一通り押して許可されているか確認してください。

## Google マップのAPIキー

`app/src/main/res/values/keys.xml` に、自分のGoogle Maps APIキーを入れてください（地図ピンの設定に使用）。

## しつこい通知の仕組み
- ⑥で設定した時間帯に自宅にいると、対象アプリを開くよう通知します
- 無視すると5分おきに再送し、対象アプリを開いてから3分以上離れると警告に切り替わります
- 警告は無視するたびに少しずつ強くなります（4段階）
- 「今日はもう休む」を選ぶと、その日はもう来ません。日付が変わると自動的にリセットされます

## 音声アシスタントの仕組み
- マイクの許可と「見守りを開始」（⑤）または「音声アシスタントを有効にする」（⑦）のどちらかでサービスが起動し、「ヘイ、デイリー」で会話が始まります
- できること: タイマー・アラーム・ライト・音量・画面の明るさ・電力モード・おやすみモード・マナーモード・アプリを開く・音楽の再生と操作・設定画面を開く
- 音楽をハンズフリーで再生するには「通知へのアクセス」の許可が必要です
- 画面の明るさ操作には「システム設定の変更」の許可、おやすみモード・マナーモード（無音）には「通知ポリシーへのアクセス」の許可がそれぞれ必要です
- 端末内AI（オフラインの頭脳）を使うには、⑦から約2.1GBのモデルをダウンロードしてください（Wi-Fi推奨）
